# Microbial dechlorination reshapes halogenated antimicrobial risk in urban river sediments

This repository contains the datasets and analysis code supporting the study:

**Microbial dechlorination reshapes halogenated antimicrobial risk in urban river sediments**

## Overview

This study investigates how in situ microbial dechlorination reshapes
the ecological risk of halogenated antimicrobials in urban river sediments.

The study includes sediment samples from 140 urban rivers across 64 Chinese cities
and integrates chemical measurements, environmental variables, socioeconomic
and wastewater-related variables, and metagenomic biomarkers.

## Repository contents

- `data/`: processed datasets used in the analyses
- `scripts/`: Python scripts for statistical analyses and risk calculations
- `figures/`: scripts used to generate the main and supplementary figures

## Software

Analyses were performed using Python 3.12.
